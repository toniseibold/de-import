# Balancing Cost Savings and Import Dependence in Germany’s Industry Transformation

This repo corresponds to the paper [Balancing Cost Savings and Import Dependence in Germany’s Industry Transformation](https://arxiv.org/abs/2510.00918).
It is based on the open source energy system model [PyPSA-DE](https://github.com/PyPSA/pypsa-de).
The following changes were made to the model:

* Endogenous implementation of the industry sector
* Including all European countries
* Coupling the model with results from [TRACE](https://github.com/toniseibold/de-import-trace) to include imports of non-European countries
